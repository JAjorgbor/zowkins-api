# PharmaHub Medica API

Robust Node.js API powerering the PharmaHub Medica ecosystem. Balanced on principles of scalability, security, and clear documentation.

## 📚 Essential Documentation

- [API Architecture](./docs/ARCHITECTURE.md)
  - Detailed look into the Route-Controller-Service pattern and validation logic.

## 🚀 Getting Started

First, install the dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm run dev
```

## 🛠️ Technology Stack

- **Runtime**: Node.js
- **Framework**: Express
- **Validation**: Zod
- **Documentation**: Swagger/OpenAPI
- **Language**: TypeScript
- **Auth**: JWT (Stateless)

## 📖 API Documentation

Once the server is running, you can access the Swagger documentation at `/api-docs` (depending on your local configuration).
